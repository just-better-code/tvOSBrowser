# Torrents on Apple TV

The browser embeds libtorrent and TVVLCKit. Open **Torrents** from the menu to paste a magnet link or an HTTP(S) `.torrent` URL. Clicking either kind of link on a page opens the library immediately. New torrents start with files skipped until you choose which to download; **Play Now (Priority)** enables the selected file. TVVLCKit plays verified pieces through a loopback HTTP range server while the remainder downloads, then opens completed files directly on later playback. Torrent data lives in `Library/Caches/BrowserTorrents`; tvOS may purge it between app launches.

Run `scripts/bootstrap-torrent-deps.sh` and `scripts/bootstrap-vlc-deps.sh` once before building. They download libtorrent 1.2.17, Boost 1.69, and the official TVVLCKit 3.7.3 tvOS device binary into ignored `.deps/`, with pinned SHA-256 checksums. The libtorrent binary is from [libtorrent-Apple](https://github.com/danylokos/libtorrent-Apple), built from [libtorrent](https://github.com/arvidn/libtorrent), which uses the BSD license. Boost uses the [Boost Software License](https://www.boost.org/users/license.html). [TVVLCKit](https://github.com/videolan/vlckit) is provided by VideoLAN under LGPL-2.1-or-later; its license is retained in `.deps/TVVLCKit-LICENSE.txt` after bootstrap.

The **Keep Alive** menu toggle loops silent audio as an experiment while the app is in the background. tvOS may still suspend the app. Leave it off unless testing background downloads. Torrent playback offers MP4, M4V, MOV, MP3, M4A, MKV, and AVI through the embedded VLC engine; supported codecs still depend on the particular file and tvOS hardware. The library's hint reports the total torrent cache size, including downloads that belong to listed torrents. **Purge All** removes cached downloads while retaining torrent entries for manual restart. Removing one torrent requests deletion of its cached payload, metadata, and saved fast-resume state. Libtorrent checkpoints verified pieces in the cache to avoid a full file check on every launch; this is still under device verification. If tvOS purges the payload, libtorrent must download missing pieces again.

The app registers tvOS refresh and processing tasks and requests runtime when a manually started torrent remains incomplete. It checks the system Background App Refresh status before submitting and responds to a change in that status. tvOS can defer, interrupt, or omit a task. The Debug build also submits a probe-only request with no torrent, and the Torrents hint shows elapsed time, timer-covered execution time, and the longest gap from the last background interval. A background task registration or submission does not establish that the system actually ran it or that a torrent transferred; see [background research](docs/agent/TVOS_BACKGROUND_DOWNLOADS.md).
