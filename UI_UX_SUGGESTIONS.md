# Пропозиції UI/UX для tvOS Browser

Це окремий список наступних поліпшень. Пункти нижче — пропозиції, а не підтверджені дефекти. Фактичні результати перевірок і відтворені збої записуються в [TEST_CASES.md](TEST_CASES.md).

## Історія

1. **Пошук і фільтри.** Для тисяч записів додати пошук за назвою/доменом та швидкі фільтри «Сьогодні», «Останні 7 днів», «Усе». Це скоротить число натискань пульта.
2. **Групування за датою.** Показувати роздільники «Сьогодні», «Учора» та дати; надати перехід між групами через пульт. Поточний плоский список складно переглядати у великій історії.
3. **Швидкий перехід угору.** За довгого списку додати явну команду «До початку» або індикатор положення. Кнопка Clear All уже закріплена зверху, але інші дії теж мають залишатися досяжними без сотень кроків.
4. **Дія над одним записом.** Окремо від режиму множинного вибору запропонувати Open / Delete для сфокусованого рядка через Play/Pause або довге натискання Select. Один клік Select зараз лише ставить позначку, що може бути неочевидно.
5. **Підтвердження видалення.** Для Clear All лишити поточне явне підтвердження; у тексті показати кількість записів. Для Delete Selected показувати кількість перед виконанням, якщо вибрано багато рядків.
6. **Порожній стан.** Після Clear All показати коротке пояснення і фокус на Done або іншій доступній дії, без «мертвого» порожнього списку.
7. **Великі дані.** На 1000+ записах перевірити швидкість появи екрана та прокрутки; якщо є затримка, завантажувати сторінками й оновлювати лічильник без повного перечитування даних при кожній дії.

## Меню та навігація

1. **Підказка пульта.** Невелика підказка в меню й історії: Select — вибір, Menu — назад, Play/Pause — дії. У тестах пункт History Actions виявився корисним, але його важко знайти без підказки.
2. **Передбачуваний фокус.** Після закриття історії або діалогу повертати фокус на елемент, з якого екран відкрили. Це зменшить повторні переходи стрілками.
3. **Постійні ключові дії.** Home, Reload, адреса, New Tab і Tabs у верхньому ряду вже утворюють зрозумілий маршрут; зберегти цей порядок при подальших змінах.
4. **Стани налаштувань.** Показувати ON/OFF з однаковою позицією й контрастом для всіх плиток, а зміну стану підтверджувати коротким візуальним відгуком.

## Пріоритет наступної ітерації

Спершу завершити `HIST-09`, `HIST-10`, `HIST-15` на ізольованих тестових даних та підтвердити `HIST-16` після відновлення керування Simulator. Потім вирішити, чи потрібні пошук і групування історії за датою.
